# Hub & Theme Tweak — Editorial Direction

**Date:** 2026-09-05  
**Status:** Approved for implementation  
**Scope:** Hub landing + blog surfaces only (wiki/study stay utilitarian)

## Decisions

| Choice | Decision |
| --- | --- |
| Tone | Editorial dark |
| Surface scope | Hub + blog editorial; wiki/study utilitarian |
| Hub composition | Feature frame — brand + headline, latest post as main block, secondary Wiki/Study links |
| Featured post | Always latest blog post by `date` |
| Approach | CSS-token editorial (Approach 1) |

## Visual system

- Base: Fumadocs `black` dark preset
- Accent: quiet warm steel `hsl(28 18% 55%)` — links/hover only
- Display: **Newsreader** for hub/blog headings
- Body/UI: Geist
- Hub: no silo cards; featured post as primary frame; text links for Wiki/Study
- Blog: larger reading measure, display headings, Related Wiki panel retained

## Out of scope

- Custom blog shell rewrite
- Motion system / hero imagery
- Wiki/study typography overhaul
