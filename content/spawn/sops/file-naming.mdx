title: File Naming
description: Consistent naming for sessions, bounces, and deliverables.
---

## Pattern

`YYYYMMDD_Client_Project_Descriptor_vXX`

Examples:

- `20260312_Example_Album_Vocals_Edit_v03`
- `20260312_Example_Album_Master_v01`

## Rules

- No spaces — use underscores
- Zero-pad version numbers
- Keep client and project tokens stable across a job
