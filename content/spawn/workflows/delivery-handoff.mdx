## Goal

Ship the right files, with the right names, and leave the project hub in a state you can reopen later.

## Steps

1. Bounce stems / masters per the client agreement
2. Run naming and loudness checks
3. Deliver via the agreed channel
4. Update the project hub status
5. Move the hub to [Archive](/spawn/projects/archive) when fully closed
